# Books Data EDA

 Project Overview
This project performs Exploratory Data Analysis (EDA) on books data using Python.

 Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook


 Files
- `EDA_2.ipynb` – Jupyter Notebook containing the analysis
- `Books_Data_Clean.csv` – Dataset used for the analysis

 Objective
To explore the books data and identify useful patterns and insights through data analysis and visualization.
